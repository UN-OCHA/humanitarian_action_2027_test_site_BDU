# Humanitarian Action 2027: test site

An interactive test version of the 2027 design proposals for [humanitarianaction.info](https://humanitarianaction.info/): homepage hero, key figures, wide cluster tables and documents and links, each in a Simple and an Advanced version. Built for testing on real devices and screen widths. **Not the live site.** Example content comes from the live and demo sites.

The designs, specs and approvals live in Figma, which is the source of truth; this site follows it. Each page ends with design notes that link to the Jira tickets (HPC-10626, HPC-10625, HPC-10606, HPC-10630).

Live: https://un-ocha.github.io/humanitarian_action_2027_test_site_BDU/
